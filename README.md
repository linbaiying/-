# 代码排练器 · CODE REHEARSAL UNIT

> 把"练琴"的习惯搬到写代码上——一台机械仪表盘风格的专注训练台。
> 单文件、零依赖、离线可用：双击 `index.html` 即可运行。

## 在线演示

部署后填写：`https://<你的域名>/`（Gitee Pages / GitHub Pages / Netlify 均可）

## 它解决什么问题

刷题、备考、练手速……"坚持练代码"比"写代码"更难。代码排练器把练习变成**可计划、可度量、可复盘**的训练闭环：

**计划 → 专注执行（防分心）→ 真实记录 → 强制休息 → 间隔复习 → 周报复盘**

## 功能一览

### 计时训练
- 10/15/25/45 分钟预设 + 1–60 分钟自定义，仪表盘指针实时扫动
- 满 45 分钟自动触发 **5 分钟强制休息**（持久化锁定，刷新也无法绕过），休息期间表盘显示倒计时 + ⛽ 加油徽章
- ☕ 独立 5 分钟休息计时（番茄工作法），随时可跳过
- 刷新/关闭页面计时**不丢失**：状态每 5 秒落盘，重开自动恢复；离开期间完成会自动补记

### 专注质量
- 计时中切走标签页会被记录为"分心"，结束时报告分心次数与离开时长
- 主动暂停不算分心，完成提示会如实注明"含暂停 X 分钟"

### 训练系统
- **今日计划**：早晨排好科目清单，完成一轮自动勾选并装载下一科
- **间隔重复**：自动识别 ≥3 天未练的科目并提醒，开始时提示"上次练习是 N 天前"
- **每日目标**：目标分钟数 + 进度条，达标变绿
- **统计仪表**：今日轮次/专注分钟/连续天数/累计时长/近 7 日强度/本周科目 TOP

### 数据主权
- 所有数据存于本机浏览器（localStorage），不上传任何服务器
- 支持一键导出 JSON 备份 / 导入合并（自动去重）
- 一键生成并复制"本周训练周报"文本

### 互联情报（折叠面板，休息时自动展开）
- 题目查询：DeepSeek / LeetCode / 洛谷 / MDN / StackOverflow 等 9 个引擎，带关键词直达
- GitHub 本周新晋热门仓库 Top 5
- 科目推荐：自动识别练习方向（算法/前端/数据库/AI 等 15 类），推送对应热文与小提示

### 细节
- 机械仪表盘视觉：SVG 刻度表盘、琥珀色数码管、状态灯排、面板螺丝
- 随机鼓励语标题、实时时钟、节日祝福（含农历节日）
- WebAudio 合成节拍音与提示音（可关闭）
- 快捷键：`空格` 开始/暂停 · `R`/`Esc` 重置 · `B` 休息 · `1-4` 选时长

## 技术实现

- 纯原生 HTML/CSS/JavaScript 单文件，无框架、无构建、无外部依赖
- 表盘为运行时生成的 SVG（刻度/数字/警戒弧），指针以 CSS 变换驱动
- 数据持久化基于 localStorage，多键分域（会话记录 / 运行状态 / 计划 / 偏好）
- 提示音由 WebAudio 振荡器合成，系统通知基于 Notification API
- 互联数据通过公开 API 获取（GitHub Search / hitokoto / dev.to），带本地缓存与离线回退
